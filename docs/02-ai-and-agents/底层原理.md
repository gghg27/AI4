# 底层原理

## 学习目标
- 大模型的底层架构原理过程（文字--->tokenizer--->embedding--->tansformer架构--->预训练--->指令微调--->偏好对齐--->任务化Lora低秩微调）
- 从claude code开始agent的学习：重点要学习明白1.核心agent循环。2.工具调用。3.skill（[从 0 搭建 Skill](../从0搭建skill.md)）。4.MCP。5.上下文管理。6.多agent系统。7.沙箱权限。8.prompt工程

## 大模型篇

在学习大模型的原理之前需要先具备一定的深度学习的知识，推荐《动手深度学习》这本书，网上有电子资源[《动手学深度学习》 — 动手学深度学习 2.0.0 documentation](https://zh.d2l.ai/index.html)
也可以在z-library上下载电子书。

在明白transformer原理后就可以开始大模型原理的学习，推荐这几个网站：

- 可以先看这个的大语言模型基础部分：[hello agents](https://datawhalechina.github.io/hello-agents/#/./chapter3/%E7%AC%AC%E4%B8%89%E7%AB%A0%20%E5%A4%A7%E8%AF%AD%E8%A8%80%E6%A8%A1%E5%9E%8B%E5%9F%BA%E7%A1%80)
- 然后再看上交出的教程，这个很详细：[Lordog/dive-into-llms: 《动手学大模型Dive into LLMs》系列编程实践教程](https://github.com/Lordog/dive-into-llms)

## Agent篇

对于Agent，推荐直接去学习claude code，今年3月份的时候cc的源码不小心被泄露，掀起了一大片的agent的研究，现在网上仍能够获取到cc的源码，也有不少的佬写了对cc的解析，这些都是可以用来学习agent的很好的资料。但是对于agent，更新迭代的速度实在是太快，现在的各种agent层出不穷，大致方向都可通过cc来学习到，只不过它是用typescript写的。

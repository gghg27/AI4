# 应用层

## agent工具

现在的agent工具已经是百花齐放了，各个大模型都开发配有自己的agent软件

- codex
- claude code
- opencode
- cursor等等

都可以自己下着玩一玩，我用的多一点的还是codex加一点claude code（可以在github上下载个ccswitch，可以用来快捷切换agent的大模型的api key配置，不用手动重复更改环境变量，也就是可以用Claude code，然后里边接deepseek的模型，具体的教程的话，dp的api platform上应该是有教程的）
 
**tips**：chatgpt里的chat模式是不会消耗限额的，只有work和codex模式会消耗额度，所以如果在额度很紧张的情况下，可以让codex给你总结一份详细的工程文件情况的prompt文档，然后交给chatgpt，与它用chat模式讨论方案，讨论好了，需要执行时，在让chat模式生成一份执行prompt文档丢给codex执行。

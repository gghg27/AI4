## skill和MCP
skill的本质就是一份md指示文档，有的会配套上已经写好的一些工具脚本，大模型会读取这些skill，按照其里面规定好的任务流程执行任务，并能够获悉到这些工具脚本的存在，并选择性的调用它们。

推荐的有：academic research、superpowers等等。可以根据你的需求让ai给你找，或者与它讨论搭建自己的skill（参见[从 0 搭建 Skill](../从0搭建skill.md)）

skill的安装方法可以问ai，也可以直接让codex安装好😆

MCP的全名叫做模型上下文协议，似乎就是让大语言模型能够通过标准化的接口，调用外部工具并操作软件。（我还没玩过，等我使用过后，再补充这一块，也欢迎补充！）

skills.sh和glama上搜skill和mcp，最好的办法就是直接有什么需求，问chatgpt，让他来找合适的。

### 使用方法

**skill**：学了底层原理会知道，skill是有全局的和调用的，全局的是直接写入或者创建一个agent.md，这是每次都会拼接进prompt里面传给大模型的。调用的方式是安装后，在输入框键入 $ 选择调用的skill。

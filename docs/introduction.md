# 引言：为什么从计算机第一课开始

这份指南写给刚进入大学、想尽快理解 AI 但还不熟悉电脑的新生。你不需要先成为程序员，也不需要相信任何“万能提示词”或“万能模型”的宣传。真正可靠的起点，是知道文件在哪里、命令会做什么、结果如何验证。

## 三部分如何配合

1. **计算机第一课**：让你看懂文件、终端、环境变量、Git 和常用开发工具。它是后续学习的地基。
2. **大模型与 Agent**：解释模型为什么能生成内容、为什么会出错，以及 Agent 如何借助工具完成任务；其中包含一条面向 AI 应用开发岗的学习路线。
3. **学习资源总库**：把我整理过的课程、网站、社区和开源项目按任务分类，帮助你继续向下学习，而不是一次性收藏很多链接。

## 推荐阅读方式

- 完全不熟悉电脑：先看第一部分，再进入第二部分的“大模型是什么”。
- 主要想提升日常学习效率：先看第二部分的“把模型用于真实任务”，随后用第三部分补基础。
- 想找 AI 应用开发实习：按第一部分 → Agent 基础 → AI 应用开发岗路线 → 动手搭 Agent 的顺序学习。
- 已经有编程经验：直接进入第二部分，遇到环境问题时回看第一部分对应页面。

## 一条重要边界

AI 能帮助你解释、整理、生成草稿和发现思路，但它不会替你承担事实错误、代码缺陷、隐私泄露或学术不端的后果。每次使用都要保留输入来源、检查输出证据，并理解自己最终提交或运行的内容。

## 内容如何维护

模型名称、价格、安装命令和外部链接都会变化。涉及产品行为的页面会标注核验日期；社区帖子只作为经验线索，不能替代官方文档。欢迎通过仓库 Issue 提交失效链接、错误说明和适合新生的资源。

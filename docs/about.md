# 关于这份指南

## 它帮助谁

这份指南帮助零到少量编程基础的大一新生安全、有效地使用 AI。完成主线后，你应当能：

- 用清楚的目标、材料、约束和验收标准描述任务。
- 理解大模型、Agent、Tool Calling 和 Harness 的基本关系。
- 安全配置 API Key，并判断第三方中转服务的风险。
- 分清 MCP、Skill 和 `AGENTS.md` 的适用场景。
- 用测试和 Git diff 验证 AI 的代码修改。

## 来源原则

产品安装、API 行为、权限和规范优先引用官方资料。社区帖子用于提供经验、学习路线和问题线索，不作为安全或产品事实的唯一依据。

可能变化的页面会标注“最后核验”日期。遇到安装命令、模型名称、价格、限额和服务条款时，请再次查看官方文档。

## 隐私与安全

示例只使用虚构数据。不要向模型或第三方中转站提交：

- API Key、密码、验证码和私钥；
- 身份证件、住址、电话号码等个人信息；
- 未公开试题、课程内部材料和实验室数据；
- 未经许可的他人作品、代码和聊天记录。

发现网页、文档或 Skill 要求你上传密钥、关闭安全检查或执行陌生命令时，先停止并核验来源。

## 学术诚信

AI 可以帮助解释概念、提供反馈和生成练习，但不能替代你的学习责任。提交课程作业前，确认学校和任课教师的 AI 使用规则。你应当能独立解释提交内容、重现实验并说明引用来源。

## 如何参与共建

提交修改时，请说明：

1. 这项内容帮助新生完成什么任务；
2. 命令或链接在哪个环境和日期验证；
3. 是否涉及账号、费用、隐私或数据风险；
4. 如何判断示例得到正确结果。

本站不是任何模型、中转站或社区的官方项目。

# 电子书下载网站
## Z-library
[Z-library](https://z-library.bz/)的域名经常更换，可以在官网上下载桌面版，任何你想要找的电子书资源（中英文）都可以先在这上面搜一下看看，注册个账号，每天最多可以下载10本。

这个网址失效了也没关系，可以直接在谷歌浏览器上搜索，大概率都能搜索到。

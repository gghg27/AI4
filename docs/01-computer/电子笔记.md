# 电子笔记

<div class="section-intro" markdown="1">

> 记电子笔记是一个很好的学习习惯，好处有很多，其一是这是一个很好的正反馈方式，能让人感觉一天下来是有收获的，即使并没进脑子，情绪价值也是到了的😅
> 
> 此外，还可以在笔记软件中接入大模型，构建属于你的个人知识库（这其实可以都当作一个动手小实践，搭建个人知识库的技术有很多，可以从最简单的chunk切片，向量相似匹配做起，到后面还可以去做知识图谱，混合型（Weknora））
> 
> 记电子笔记还便于与别人共享，与ai对话
> 
> 总之**markdown语法是必学的**！！！

</div>



电子笔记的软件大同小异，本质上都是文件系统加markdown渲染，市面上有很多的软件，比较推荐的是obsidian，这个软件的插件下载很方便，刚开始上手的时候得花费点时间适应一下。
主要在于学会markdown语法，其实也很简单，也就几个常用的。可参见[Markdown 语法详细教程](Markdown语法详细教程.md)

对于软件的学习可以参见知乎上的文章：[想一小时上手obsidian？这一篇就够了。【玩转Obsidian的保姆级教程】 - 知乎](https://zhuanlan.zhihu.com/p/428519519)

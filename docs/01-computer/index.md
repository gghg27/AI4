# 第一部分：缺失的计算机第一课

<div class="section-intro" markdown="1">

> 很多人其实在上大学之前都没有怎么接触过电脑，对于电脑的文件系统、终端这些概念没怎么听说过，但我们大部分的课程却都默认我们很熟悉这些操作。
> 
> 这是一个很普遍的事情，对于这样的一门缺失的计算机课，有一些学校已经注意到了这一点并开设了相应的课程，网上也有很多的计算机扫盲教程，所以需要解决的第一点是要会用你的电脑。即使会用了也可以花点时间刷一遍，其实也花不了太多的时间，说不定会偶然间刷新你对电脑的理解。
> 
> 我在上大学前其实就经常玩家里的电脑，但玩游戏和搞技术开发还是不太一样，我大一上C语言实验课的时候就特搞不明白那个软件，哪怕我在高中的时候还学过C语言，代码上花的时间其实并不多，大部分都是在和环境、终端、软件作斗争，大部分能操作的空间只有代码编辑框和运行按键，害怕点错了其他的，又报一堆看不明白的报错😂😂😂😂
> 
> **工欲善其事必先利其器——所以花时间完成一次计算机的扫盲是有必要的**
> 
> 此外，我还汇总了一些进阶的一点的往往默认你已经会了的技能。总之，和计算机技术相关的我都总结在这一部分。
> 

</div>

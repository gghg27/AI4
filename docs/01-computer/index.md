# 第一部分：计算机第一课

> **目标：** 能定位文件、读懂命令、管理开发环境，并安全地运行一个小项目。

很多 Agent 教程默认你已经知道当前目录、环境变量和 Git。本部分只讲继续学习 AI 所需的最小计算机基础。

## 最小练习

在一个空目录中创建 `notes.md`，用 PowerShell 查看当前位置和文件，再初始化 Git 仓库并查看 `git diff`。每条命令执行前先说清楚：它读取什么、写入什么、失败时会留下什么。

## 学完自测

- 我能区分绝对路径和相对路径吗？
- 我知道 PowerShell、CMD 和 Bash 为什么不能完全混用吗？
- 我能在不泄露密钥的情况下配置环境变量吗？
- 我能用 Git 查看 Agent 修改了哪些文件吗？

# 信息搜集

比较万能的一个办法是上google进行关键词搜索，eg：如果想要搜和情绪识别相关的脑电识别项目，就可以在google搜索框里键入：‘github’
‘EEG’ ‘emotion recognition’

还有一个最万能的办法就是把你的需求描述明白，直接给网页版的gpt。
## 文献获取

- 可以通过学校图书馆内的各个平台进行搜索获取
- 对于外文文献可以在tb上买一个账号，一般都汇集了很多主流的文献资源
- 对于实在难以下载的文献还可以使用学校图书馆或者购买的网上账号里的文献求助平台
- 如果连求助也没办法获取的话，就上小黄鱼和tb找文献带下吧
